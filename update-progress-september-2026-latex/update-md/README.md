# Update Progress AuditChain Gateway September 2026

Folder ini dipakai untuk catatan markdown tambahan sebelum dipindahkan ke file LaTeX.

Struktur utama:

- `main.tex`: file utama LaTeX.
- `chapters/`: isi bab laporan.
- `images/`: tempat screenshot atau diagram.
- `output/`: hasil build PDF.
- `build.bat`: build cepat di Windows.
- `build.py`: build via Python.

Cara build:

```bat
build.bat
```

Atau:

```bash
python build.py
```

Output final akan berada di:

```text
output/Progress_AuditChain_Gateway_September_2026_Lengkap_Update.pdf
```
